# Basketball Stats Tracker — Promo Video

16-second product presentation built with [HyperFrames](https://hyperframes.dev).

## Quick Start

```bash
pnpm install
pnpm preview
```

## Scripts

| Command | Description |
|---------|-------------|
| `pnpm preview` | Live preview |
| `pnpm render --output video.mp4` | Render to MP4 |
| `pnpm lint` | Lint composition |

## Structure

- `index.html` — Composition (16s, 5 scenes, audio)
- `screenshots/` — App screenshots
- `audio/` — Background music
